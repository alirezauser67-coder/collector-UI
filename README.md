# جمع‌آوری کانفیگ V2Ray / Xray

> [English version](README_en.md)

یک برنامه گرافیکی ساده برای دریافت کانفیگ‌های V2Ray و Xray، پیدا کردن کانفیگ‌های میزبانی رایگان و بررسی زنده بودن آن‌ها.

## امکانات

- پشتیبانی از منابع متنی، Base64، فایل محلی و چند subscription هم‌زمان
- پشتیبانی از `vless`، `vmess`، `trojan`، `ss`، `ssr`، `tuic`، `hysteria2` و `wireguard`
- فیلتر بر اساس دامنه سرویس‌های میزبانی رایگان
- بررسی TCP و HTTP برای تشخیص کانفیگ‌های `LIVE`، `DEAD`، `DOWN` و `PORT OPEN`
- فیلتر، مرتب‌سازی، کپی و ذخیره نتایج
- رابط تیره و روشن

## لینک سابسکریپشن

```text
https://raw.githubusercontent.com/alirezauser67-coder/collector-UI/refs/heads/main/configs.txt
```

این فایل هر روز ساعت ۱۰:۰۰ UTC به‌صورت خودکار به‌روزرسانی می‌شود. فایل `e2econfig.txt` هم کانفیگ‌های بررسی‌شده و سالم را نگه می‌دارد.

## پیش‌نیازها

- Python 3.10 یا جدیدتر
- Tkinter، همراه نصب رسمی Python برای Windows
- اتصال اینترنت

برنامه به کتابخانه خارجی نیاز ندارد.

## اجرا

```powershell
python collector_ui.py
```

برای اجرای دستی بخش جمع‌آوری خودکار:

```powershell
python scripts/collect.py
```

## راهنمای سریع

1. با `F5` منابع subscription را اسکن کنید.
2. با `F6` کانفیگ‌های پیدا‌شده را از نظر زنده بودن بررسی کنید.
3. از فیلترها و انتخاب سایت برای پیدا کردن نتیجه مناسب استفاده کنید.
4. نتیجه را با دوبار کلیک یا `Ctrl+C` کپی و با `Save...` ذخیره کنید.

| وضعیت | معنی |
|---|---|
| `LIVE` | پاسخ HTTP موفق دارد |
| `DEAD` | سایت یا سرویس خطا داده است |
| `DOWN` | اتصال برقرار نشده یا زمان انتظار تمام شده است |
| `PORT OPEN` | پورت باز است، اما پاسخ HTTP دریافت نشد |

## کلیدهای میانبر

`F5` اسکن · `F6` بررسی زنده بودن · `F7` بررسی سایت انتخاب‌شده · `Esc` توقف · `Ctrl+C` کپی

## فایل‌های مهم

- `collector_ui.py`: برنامه گرافیکی
- `scripts/collect.py`: جمع‌آوری خودکار
- `sources.txt`: منابع subscription
- `configs.txt`: خروجی خودکار

فقط از منابعی استفاده کنید که اجازه دسترسی به آن‌ها را دارید.
